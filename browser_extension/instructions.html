Browser integration setup

Connect this extension to the My Download Manager desktop application.

This extension's ID

Your extension ID: …

You need this ID when registering the native messaging host.

1. Build the native host (once)

In PowerShell, from the project folder:

powershell -ExecutionPolicy Bypass -File .\native_host\build_host.ps1

2. Register the native host

Google Chrome:

powershell -ExecutionPolicy Bypass -File .\native_host\install_native_host.ps1 -ChromeExtensionId <ID>

Microsoft Edge:

powershell -ExecutionPolicy Bypass -File .\native_host\install_native_host.ps1 -EdgeExtensionId <ID>

Both IDs can be given in one command. No administrator rights are needed.

3. Restart the browser and start the application

  1. Close every window of the browser and open it again.
  2. Start My Download Manager. The top bar shows Browser integration ready.
  3. Right-click any HTTP or HTTPS download link and choose Download with My Download Manager.

4. Automatic capture (optional)

  1. Open the extension popup and choose Ask before downloading or Automatic under Automatic capture. The browser asks for permission to manage downloads and to read request details on websites; capture stays off if you decline.
  2. File types and excluded websites are managed in My Download Manager under Settings › Browser Integration (the popup button opens it).
  3. Only plain GET downloads of selected file types are captured. Private-window downloads, downloads flagged as dangerous, and downloads that need your sign-in stay in the browser.

Troubleshooting

  • Native host unavailable – the host is not registered, or was registered for a different extension ID. Re-run the install command with the ID shown above, then restart the browser.
  • Application not running – start My Download Manager. Requests that could not be delivered stay in the popup so you can retry them.
  • Connection error – check that MyDownloadManagerNativeHost.exe still exists where it was installed. The host log is at %LOCALAPPDATA%\MyDownloadManager\logs\native_host.log.
  • Only HTTP and HTTPS links are supported. Cookies and logins are not shared with the application, so links that need you to be signed in may fail.
